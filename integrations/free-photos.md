# 免费图库集成（Pexels / Pixabay）

配图三级降级中的**第二级**：生图失败或内容被拒时，改从免费图库取图；再失败才退纯色背景。

## 一、定位

- 只用于**背景与氛围类**图片（封面、章节页、结尾页）；
- 不用于承载信息的图（数据、流程、结构图一律原生对象）；
- 图库图同样要叠蒙版，保证白字对比度 ≥ 4.5:1。

## 二、凭证

| 图库 | 环境变量 | 说明 |
|---|---|---|
| Pexels | `PEXELS_API_KEY` | 默认优先 |
| Pixabay | `PIXABAY_API_KEY` | Pexels 失败或无结果时 |

- **Key 只从环境变量读，禁止写进 `config.json`、脚本或任何文件**；本包只记录"存在与用途"，不记录值。
- 未配置 Key 时：`search_photos.js` 直接跳过本级并输出 `info` 级提示，流程继续走向纯色降级。

## 三、调用

```bash
node scripts/search_photos.js --plan output/plan.json --candidate A \
  --query-map output/photo_queries.json --fill output/photos
```

脚本行为：

1. 只处理 `image_required: true` 且当前 `image_path` 为空的页；
2. 用页面 `image_type` + 主题意象拼检索词（英文优先，避免检索命中率过低）；
3. 过滤条件：横版（`orientation=landscape`）、宽度 ≥ `config.json` 的 `photos.min_width`（默认 1600）、免费授权；
4. 下载后回填 `image_path` 与 `photo_source`（图库名 + 图片页 URL + 作者 + 授权类型）。

## 四、授权纪律

1. 只使用标注为免费授权的图片（Pexels License / Pixabay License），不得使用需署名外的受限素材；
2. **交付说明中必须列出每张图库图的来源链接与授权类型**；
3. 不得使用带水印、疑似他人品牌标识或含可识别人物的图片；
4. 用户明确要求"不要用图库图"时，直接跳到纯色降级。

## 五、失败与降级

| 情况 | 处理 |
|---|---|
| 无 Key | 跳过，记 `info`，退纯色 |
| 检索无结果 | 换更宽泛的英文词重试 1 次；仍无 → 下一张库或退纯色 |
| 下载失败/尺寸不足 | 同一张最多重试 1 次，仍失败退纯色 |
| 命中受限内容 | 换词重查，不强行使用 |

## 六、自检

- [ ] 每张图库图都有来源与授权记录
- [ ] 图片为横版且宽度达标
- [ ] 作为背景时已叠蒙版且文字对比度达标
- [ ] 未把图库图片用于数据/流程/结构表达
- [ ] Key 未落盘到任何文件
