# 更新日志

本文件记录 PPT 设计台（smart-ppt-studio）的可见变更。日期为提交日期。

## 1.8.0 — 2026-11-23

### 新增

- **导入模板后生成结构速览**：解包 `.pptx` 后读出现成的数据（页数、每页文字块与字数、图片数、主题色），据此推断页面框架（封面 / 目录 / 章节页 / 内容页 / 图文页 / 结尾页），并列出「你可能需要准备」的素材与数据。全部本地解析，不调用模型，不消耗 token。
- **可选深度分析开关**：导入时勾选后，记录里会附带一份待分析指令，可交给会话里的模型做更细的框架解读。默认关闭，选择按浏览器记住。
- **动效配方扩到 18 条**：并入 ppt-effects v1.2.0，新增效果16 扫光动画、效果17 纵横导航栏、学术导航0（偏学术版，四色可选）。

### 改进

- **模板可用性如实上报**：新增 `/smart-ppt-studio/probe` 宿主路由，导入面板启动时批量探测模板文件是否存在。此前每条模板都写着「本机可用」，而仓库版并不含 `.pptx` 本体，导致装上後每张卡片都点不开。
- **空态引导**：本机没有任何可用模板时，直接说明「仓库版不含模板文件」，并给出两条出路——自行导入，或改用自由生成。计数同步显示真实可用数。
- **面板背景**：由单层线性渐变改为三层主题色径向柔光 + 一条缓慢漂移的光带。所有颜色由 `--dsw-alias-*` 混合而来，随宿主亮/暗主题自动适配；系统开启「减少动效」时自动静止。
- **界面文案与真实版本对齐**：修正面板中长期残留的 `9.0.2`、`共 18 个视觉系统`、`28 条红线`、`v5.6 压缩包` 等旧值，统一为 9.0.8 / 19 套 / 29 条 / 13 步 / 32 条 / 18 条 / 95 份。

### 说明

- 模板文件不随仓库分发：随包提供的是模板清单，`.pptx` 本身体积过大且属于第三方素材。需要模板的用户请通过面板里的入口联系作者。
- 结构速览的框架推断使用启发式规则，不是模型判断；复杂或非典型的排版可能归错页型。需要更准确的结果请在导入时勾选深度分析。

## 1.7.0 — 2026-11-16

- 缩略图路由接入 DSH 的 Host/Origin 准入：`webServer` 上注册的路由先于 Connection 的信任检查执行，现于处理函数入口调用 `ctx.connection.requestRejection({ headers })`，被拒时返回 401/403。

## 1.6.0 — 2026-11-15

- 模板库支持导入本地 `.pptx`，在浏览器内抽取封面缩略图作为预览，导入记录保存在本地存储。
- 模板预览改为前端内联，不再依赖宿主缩略图路由。
