# 侧边栏插件优化说明（v1.3.1 → v1.4.0）

日期：2026-11-06　技能包：smart-ppt-designer 9.0.2

## 一、先体检，不凭感觉改

写了 `_plugin_health.py` 逐项验证，查出 **9 个问题**，其中 3 个是真 bug：

| 问题 | 实测 |
|---|---|
| 红线只显示 21 条 | 数据有 28 条，**缺 7 条** |
| 命令只显示 13 条 | 数据有 14 条，缺 1 条 |
| `rebuild_client.py` 静默失效 | 用固定字符串 `length: 19` 做替换，值一变就再也匹配不上，但脚本仍打印「已重建」 |

根因：重建脚本靠 `src.replace("Array.from({ length: 19 }...")` 这类**写死旧值**的字符串替换。
某次重建把值改成 21 后，下一次就匹配不上了——于是条数长期与数据脱节，还一直显示成功。

## 二、修了什么

### 1. 重建脚本改正则替换（根治复发）
`rebuild_client.py` v2：

- 用 `re.subn(r'Array\.from\(\{\s*length:\s*\d+\s*\}', ...)` 匹配「任意当前值」，替换成数据实际条数
- 每处替换**校验命中次数**，0 命中直接报错退出，不再静默成功
- 新增 `sub_count()` 封装，STYLE_DATA / ZH / EN / 三处条数共 6 项全部走它

### 2. 数据抽取补全（`sync_from_skill.py` v2）
- 命令不再只从 `SKILL.md` 抽：追加扫描 `scripts/` 目录，为「包里有但 SKILL.md 没列」的脚本自动补标准命令
  → 补回 9.0.2 新增的 `build_layout_library.py`、`check_layout_similarity.py`，命令 14 → **16**
- 版本号正则支持三段（`9.0.2` 不再被截成 `9.0`）
- 从技能包 `config.json` 读用户偏好，写进 `data/styles.json` 的 `preferences`
- 从 `references/visual-motifs.md` 抽视觉母题示例（`茶芽 / 叶脉线 / 茶渍纹`）供命令页展示

### 3. 生成指令变成「偏好感知」
`buildPrompt()` 现在会带上：

- 封面主标必须 AI 书法 PNG、仅此一处可为图片
- 你指定的书法提示词（狂野奔放 / 飞白 / 白底黑字）
- 亮底禁纯金字（WCAG 1.38），改深靛蓝 / 墨褐
- 左实右虚渐变蒙版（左 94% → 右 0%）及正确插层位置
- 背景明亮不返深色、生图工具 `image_generate`
- 9.0.2 新红线 26 构图两硬约束（1/3 大块 + 叠压对）

偏好从 `STYLE_DATA.preferences` 读，**数据驱动**，技能包改了插件自动跟着变。

### 4. 命令页补视觉母题提示
新增 `commands.motifHint` 文案 + 从规范抽出的母题示例，9.0.2 的新能力在侧边栏可见。

### 5. 复制失败有回显
原来定义了 `action.copyFailed` 文案却从不显示；现在 `navigator.clipboard` 不可用时明确提示「请手动选中文本」。
