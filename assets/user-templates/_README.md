# 用户模板库（索引，v9.0.3）

依据规格 v9.9 前置功能「模板填充模式」。**本目录只放索引，不放模板原文件。**

## 一、为什么这里没有模板原文件

用户上传的模板共 **95 份 / 7.3 GB**（另随附 84 个字体）。随包分发不现实，按已确认口径：**只建索引、按需读取原文件**。所以把技能包拷给别人时，本目录里的索引在、模板原文件不在——这是预期状态，按 `INSTALL.md` 的指引补充即可。

## 二、文件

| 文件 | 内容 |
|---|---|
| `index.json` | 95 份模板：`id` / 名称 / 原路径 / 页数 / 尺寸与画幅 / 主题字体 / 主题色 / 风格标签 / 关键词 / 体积 |
| `fonts-index.json` | 84 个随附字体：文件 / 字体族 / 字重 / 来源路径（**只登记，不复制、不安装**） |
| `_README.md` | 本说明 |

## 三、按需读取规则（硬约束）

1. **先读索引**（几 KB 的小文件），按关键词或风格标签检索出 **2–3 份候选**；
2. 只按需读取这 2–3 份原文件，**不得整体读取全部模板**（95 份全文读取既慢又浪费上下文）；
3. 索引里的 `path` 指向原文件位置；该路径不存在时（模板被移动或清理），按 `scripts/check_assets.py` 的提示让用户重新指定目录并刷新索引；
4. 选定模板后的填充流程（询问用哪份 → 封面字体保持原样或升级书法烫金 → 读取 → 填充 → 素材补充 → 风格锁定）见 `references/user-templates.md`。

## 四、刷新索引

素材新增或目录变动后重跑：

```bash
python scripts/index_user_templates.py                        # 用内置的两个素材目录
python scripts/index_user_templates.py --source "D:/新目录"    # 指定目录（可多次传入）
```

## 五、字体

**只登记不安装**。生成稿优先使用开源可商用字体（霞鹜文楷 / 思源黑体 / HarmonyOS Sans / MiSans / EB Garamond 等）；确需使用清单里的字体时，请先自行确认授权再安装。

## 六、与「安装与素材补充」的关系

把技能包拷到别的机器后，运行 `python scripts/check_assets.py` 会列出**缺失的素材项与补充步骤**（该脚本只提醒、不阻断）。完整说明见包根 `INSTALL.md`。
