# 风格卡片：暗金夜·科技国金（`tech-gold-noir`）

- **模式**：深色｜**来源**：目标案例库（用户提供的国金案例图 case-05 / 07 / 08）
- **配色**：底色 `#0B0B10`｜主色 `#1F1B16`｜次色 `#3A2F1D`｜强调 `#E7B437`｜正文 `#FFFFFF`｜浅文字 `#C9BFAA`
- **字体**：标题 微软雅黑／正文 微软雅黑
- **装饰特征**：glow_line（发光细线）/ gold_hairline（金色描边）/ gold_facet（金色切面章节页）
- **卡片样式**：近黑半透明底（86%）+ 金色细描边 + 左上图标位 + 标题条
- **代表布局**：封面大字压图、四 / 六宫格卡片、数据卡 + 金色图表、财务与商业模式页
- **来源样例**：`assets/target-cases/case-07-huixin-keji.jpg`、`case-08-huixin-keji-finance.jpg`、`case-05-zhihui-kuangshan.jpg`
- **关键词**：科技、暗金、金奖、互联网+、创赛、硬件、商业模式、财务、路演、国金

## 校准说明

按目标案例图**目视取色**（未做像素级取色）：近黑底 + 金色强调 + 发光细线。补到原件后应重新提取校准。

## 适用场景

面向创赛 / 互联网+ 金奖路演、硬科技与商业模式类项目；深色底投影效果好但**打印偏暗**，打印场景请改用浅色系统（如 `red-gold`、`medical-tech-white`）。

调用方式：页面计划 `design_brief.visual_system` 填 `tech-gold-noir`，并写明 `style_rationale`（本包不设默认风格）。
