# 封面书法主标 · 生成提示词模板（默认，用户指定）

> 来源：用户 2026-11-05 明确指定「以后优先用这个」。
> 凡是封面要 AI 书法主标，先套这个模板，再只替换书名号里的文字。

## 一、默认模板（复制即用）

```
手写书法字“<主标文字>”，四个汉字横排，字体狂野奔放，笔画飘逸，富有动感张力，
飞白，国风，中国书法，笔触流畅，白底黑字。
纯白背景，纯黑墨迹，不要彩色，不要阴影，不要立体，不要透视，不要样机，
不要边框，不要印章，不要落款，画面内不出现任何其他文字或图形，
四周大幅留白，16:9 横版
```

### 为什么带这些负向约束
生图模型默认会给书法加：立体浮雕、金色渐变、卷轴装裱、印章落款、随机英文。
这些都会让主标变成「素材站风格」，必须逐条禁掉。

## 二、调用

直接用内置 `image_generate` 工具（本机已配 qwen-image-2.1-pro，实测 8.6s）：

```
image_generate(prompt="<上面的提示词>", size="1536x1024")
```

兜底（仅当 image_generate 不可用时）：
```bash
python ~/.dsh/skills/ppt-master/scripts/image_gen.py   --backend qwen --aspect_ratio 16:9 --image_size 2K   --output <目录> --filename shufa_a "<上面的提示词>"
```

一次出 2–3 张候选，再按下面的客观指标 + 人眼挑一张。

## 三、客观筛查（模型看不了图时用）

```bash
python _shufa_check.py <目录>       # 验横排、留白、峰数
```

- 边带墨 < 2% → 四周留白够
- 高宽比 < 0.45 → 横排
- 墨量 10–20% → 不过疏不过糊
- 「狂野度」= 飞白比例 + 笔画曲折度，取最高者

> 注意：峰数会被字内笔画空隙干扰，6–7 峰不代表字错，**不能**据此判字数。
> 字形最终仍需人眼确认；若本机视觉模型可用，先跑 OCR 再交付。

## 四、转透明与配色

白底黑字 → 透明（越暗越不透明，alpha ×1.6 让笔锋实）→ 按墨迹包围盒裁切
→ 染色。配色按背景对比度定，不固定金色：

| 底色 | 推荐字色 | 说明 |
|---|---|---|
| 暖米白 #F7F4EC | 深靛蓝 #1A3A5C（对比 6.5） | 有书卷气，与金色点缀冷暖对比 |
| 暖米白 | 墨褐 #1F1B16（对比 9.5） | 最稳，但略平 |
| 深色底 | 金色渐变 #C9A227 | 金字只在深底上成立 |

**金色在亮底上不可用**：金 #C9A227 亮度 165、米白底 192，WCAG 仅 1.38，
必然糊。若坚持用金，须配深墨描边或落地投影，且描边要 ≥6px 才在成品里可见。

## 五、验收

渲染后测书法区 WCAG 对比度 ≥ 4.5（大字 3.0），且墨迹占该区 15% 以上
（太低说明字太小或没渲染出来）。
