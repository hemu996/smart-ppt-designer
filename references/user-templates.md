# 模板生成模式与模板填充规范（v9.0.3）

> 依据：规格 v9.9 前置功能「模板生成模式（二选一）」与「模板填充模式（用户上传模板）」。

## 一、两种模式：生成前必问

**每次生成前先问用户用哪种模式**（与"要不要章节导航""要不要用动效配方"同一档次的前置询问）：

| 模式 | `template_mode` | 做法 | 适合 |
|---|---|---|---|
| **自由生成**（默认） | `free` | 从素材库检索风格自由设计版式，受「模板校验兜底」约束（布局偏离常见布局时退回） | 新主题、想让 AI 设计 |
| **模板填充** | `fill` | **完全照搬**用户选定模板的版式，只替换文字 / 数据 / 图片 | 想沿用某个已满意的版式 |

判定不出时**先问用户**，不要默认走某一模式。

## 二、模板填充流程（六步）

1. **先读索引再挑模板**：读 `assets/user-templates/index.json`（几 KB），按关键词或风格标签挑 **2–3 份候选**并把摘要（页数 / 风格 / 主题色 / 一句话）给用户，让用户定——**不得整体读取全部模板**；
2. **封面字体与人物形象**：先问封面字体是「保持原样」还是「升级为书法烫金」（升级走 `assets/calligraphy-prompt.md` 的书法主标模板 + 红线 28）；**若模板封面上的人物形象不对（不是我们的人 / 身份气质不对），按 `references/cover-persona-swap.md` 五步法处理**——读图 → 拆人物描述 → 归类（人物类别 + 视觉级别）→ 用类别文案生成 → 并排核对"同级效果"。**不许直接改 prompt 换个人**，否则画风/级别一塌，整页就废；先在本机编目素材里找同类别同级别的现成图（`python scripts/find_asset.py --kind ppt_asset <关键词>`），找不到才生成。原模板里的团队信息一律清掉；
3. **读取选定模板**：只读这一份（把它的母版、版式、占位结构读进来）；
4. **填充内容**：逐页替换文字 / 数据 / 图片，**保持版式与母版不动**；接口不对（占位比内容多或少）时如实说明，不擅自改版式；
5. **素材补充**：缺图按三级降级补（生图 → 图库 → 纯色），补进的图要落到模板槽位尺寸；
6. **风格锁定**：填充后**不得引入第二套配色 / 字体 / 图标风格**；封面若升级书法，其余页保持模板原样。

## 三、硬约束

- **照搬就是照搬**：模板的版式、母版、页序不重排、不"优化"；如模板本身与包内红线冲突（例如导航画法、字号区间），**以模板为准**，但要在交付说明里如实标注差异；
- 模板里的**原案例标识**（Logo / 账号 / 水印 / 页码暗示）要清掉，不复制、不改写、不虚构替代；
- 模板缺失原文件时（拷包到别的机器）按 `scripts/check_assets.py` 的提示让用户补充；
- **不设默认模板**：没有用户指定或索引无匹配时，回到自由生成模式，不要硬挑一份。

## 四、计划里怎么写

```json
"design_brief": {
  "template_mode": "fill",
  "user_template": "ut-012"
}
```

- `template_mode`：`free` / `fill`，缺省按包级默认 `free`；
- `user_template`：`fill` 时**必填**，取索引里的 `id`（如 `ut-012`）或模板名；
- 填了 `user_template` 但 `template_mode` 不是 `fill` → 校验器提示"模板已指定但模式为自由生成"。

## 五、校验规则（`validate_plan.py`）

| 规则 | 级别 |
|---|---|
| `template_mode` 非法（不在 free / fill） | error |
| `template_mode: fill` 但没写 `user_template` | error |
| `user_template` 在索引里查不到 | error |
| 索引里查得到、但原文件不在本机 | warn（提示按 check_assets.py 补充） |
| 未声明 `template_mode` | info（按默认 free 处理，生成前应问用户） |

## 六、常见坑

1. **把 95 份模板全读一遍**——索引就是为省这一步存在的，只读 2–3 份；
2. **填充时顺手"改进"版式**——不行，填充模式的价值就是版式不动；
3. **封面升级书法后全篇换字体**——只升级封面主标，其余保持模板原样；
4. **模板里有原团队信息**——清掉，不要沿用别人的队名与标识。
