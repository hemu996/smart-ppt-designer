# 国赛水准对齐口径与升级目标（v8.7）

把"向国赛/国金水准靠拢"翻译成**可度量、可校验**的口径：用素材库同一套方法量参考稿，也量自己的稿，逐项看差距，再定升级目标。

## 一、度量方法（与素材库台账同一把尺）

- 工具：`scripts/analyze_reference.py`——静态解压 XML、**全树遍历**（含组合内部形状与字号），不启动 PowerPoint、不调 COM；
- 命令：`python scripts/analyze_reference.py --file <任意 pptx> --out-dir <目录>`，读 `<slug>.json` 的 `summary`；
- 用到的列：形/页、组/页、图/页、色数/页、最大字号、字号跨度、大图占比、版式数、转场页数、动画页数。

## 三、差距意味着什么（不是"多加元素"）

- **形/页 3× 差距**来自"基础图元拼版 + 装饰成组"：参考稿用大量 `rect / roundRect / ellipse / line / chevron` 做装饰与结构线；本包此前每页只有十几个元素，装饰还是孤立单元素。
- **组/页 0** 说明没有"先做组件、再整组复用"：参考稿把导航、卡片、编号块做成组反复用，本包此前是每页重画。
- **最大字号不足** 说明封面/章节页的"超大字号"没做足：参考稿用 187–287pt 的标题/编号承担视觉冲击。
- **图/页 0** 说明缺"封面级背景图 + 概念插图"，视觉档次直接少一档。

## 四、v8.7 升级项（按影响排序）

1. **装饰组库 + 高阶配方**（`assets/decoration-sets/`）：1 个计划元素 → 多形状成组绘制，把内页密度提到 形/页 ≥55，同时守住"纯装饰 ≤1/3"。
2. **组件复用**（计划 `components` + 页内 `use_component`）：跨页整组复用，落地为真实 PowerPoint 组，组/页 ≥6。
3. **超大字号层级**：封面 / 章节过渡页 / 结尾页建立 120–287pt 层级，最大字号 ≥187pt。
4. **可插拔生图**：封面 / 章节 / 结尾页配图 1–2 张，provider 接口（DSH `dsh.image` 优先，本机可用生图能力兜底）。

## 五、校验落点

- `scripts/score_deck.py` 的**国赛对齐度**分项：按 `config.json:gsl_alignment.targets` 与本口径打分，并逐项输出差距；
- `scripts/validate_plan.py`：装饰组存在性与分层、组件引用有效性、超大字号层级、配图预算；
- 生成前自检：`references/evaluation-rubric.md` 的对应条目；
- 生成后**观感对照**（人工终审项）：对照 `assets/target-cases/` 的 10 条共性逐条核对，缺哪条在交付说明里写明。

## 六、诚实边界（为什么不能承诺"一比一"）

1. **不是设计师手笔**：本包给的是可复用的结构、手法与规范，不产出原创美术设计；
2. **素材与字体依赖环境**：国赛稿常用商用字体与定制插画，本包受白名单字体与可用生图能力限制；
3. **复杂图示**（三维图表、手绘信息图、动态演示）超出静态构建范围；
4. 因此本文档的口径是"**结构密度与视觉手法对齐**"——把可量化、可复用的那部分做足；观感与创意部分仍需人工终审微调。
## 七、国金成品观感基准（目标案例库 `assets/target-cases/`）

素材库（结构与手法）+ 目标案例库（成品观感）两把尺子一起用。目标案例库共 10 条共性（完整逐图拆解见 `assets/target-cases/_README.md`）：

1. 满幅底图（实景照片或深色科技底 + 微弱纹理/网格/粒子/光斑），不出现大面积纯色平铺；
2. 书法 / 渐变大标题（金、橙绿、米黄），主标题 100–300pt，常与副标题细线成组；
3. 一页一母题：封面 = 主标题 + 副标题 + 3–4 枚信息标签 + 赛事 LOGO；
4. 顶部标签导航 + 统一页眉页脚；
5. 章节指示（左/右竖排标签或进度条）跨页复用；
6. 卡片化布局（四/六/八宫格 = 细描边 + 半透明底 + 图标位 + 标题条 + 小图）；
7. 实拍照片大量使用（人物/实物/场景，跨框出血、异形裁切）；
8. 数据可视（大数字 + 单位 + 小字说明；图表用主题色而非默认蓝）；
9. 页底或页中一句结论条（正式表述，不是短剧金句）；
10. 收尾整齐（编号目录卡、致谢页、版权页脚统一）。

对照本包的落地状态见该文档第三节"差距清单"；已落地：装饰密度（形/页 63.1、组/页 3.4）、网格纹理与光斑组、卡片基础样式、顶部标签导航、原生图表配色。
未落地（v8.7 后续项）：实拍/抠图大图、竖排章节标签、目录编号卡版式、卡片"图标位+标题条"变体。
