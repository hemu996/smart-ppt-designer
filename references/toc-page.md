# 目录页规范（`slide_type: toc`，v8.7）

对照目标案例库（`assets/target-cases/`）的目录页做派：**编号卡并列**，不是文字列表。

## 一、页面结构

| 要素 | 要求 |
|---|---|
| 页标题 | 「目录 / CONTENTS」或一句话说明目录覆盖范围 |
| 编号卡 | 4–6 张，2×3 或 2×2；每张 = 序号 + 章节名 + 一句话说明 |
| 版式 | `toc-number-grid`（`assets/layout-templates/toc-number-grid.json`） |
| 卡片样式 | 半透明底 + 细描边 + 左上图标位 + 标题条（按所选视觉系统的 `card_style`） |
| 页脚 | 项目名 + 页码（与其他页一致） |

## 二、校验与构建约束

- `slide_type` 取 **`toc`**（`validate_plan.py` 的 `SLIDE_TYPES` 已收录）；
- 目录页**不需要** `section_name`（不属于导航高亮的内页类型）；
- 目录页**不受**「行动标题必须是完整结论句」约束（与封面 / 章节过渡页 / 结尾页同列）；
- 构建时映射到 `CONTENT_NAV` 母版并使用封面级大字号处理；
- 章节名必须与 `design_brief.sections` 完全一致，保证后续内页导航高亮能对上。

## 三、位置建议

目录页放在**封面之后、第一个章节之前**；路演稿若有时长限制，目录页可省，但不得省章节过渡页。
