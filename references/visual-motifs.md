# 视觉母题规范（v9.0.2）

> 依据：规格 v9.3 §4.1「视觉母题规则」（L258–266）。解决「统一但不单调」——整份稿子装饰风格一致，又不至于每页重复同一个图案。

## 一、什么是视觉母题

母题 = **装饰性母题元素**（例：茶叶、叶脉、茶芽、茶渍纹理 / 齿轮、电路纹、光点 / 云纹、回纹、印章）。在初始化阶段选定 **3–5 种**，整份 PPT 复用。

母题有主有次：

- **1 个主母题**——出现频率最高，作为整份稿的识别符号；
- **2–4 个次母题**——辅助点缀，与主母题搭配。

## 二、初始化（工作流第 2 步「设计规范确认」时定）

与视觉系统同步选定，写入页面计划的 `design_brief.visual_motifs`：

```json
"visual_motifs": [
  { "name": "茶芽",   "role": "primary",   "source": "生图",
    "note": "主要点缀，封面 / 章节页 / 内容页边角复用" },
  { "name": "叶脉线", "role": "secondary", "source": "decoration_set:hand-drawn-lines",
    "note": "标题装饰线与分割线" },
  { "name": "茶渍纹", "role": "secondary", "source": "手绘", "note": "背景淡纹样，透明度 8–14" }
]
```

字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | 是 | 母题名，元素引用时用它对齐（不得重名） |
| `role` | 是 | `primary`（**恰好 1 个**）/ `secondary`（**2–4 个**） |
| `source` | 否 | 落地载体：装饰组 `set_id`、或「手绘」「生图」 |
| `note` | 否 | 用在哪、怎么用 |

**不设默认**：母题必须按内容推导后选定并写明来源；判断不出时先问用户（与视觉系统同一口径）。

## 三、只约束装饰元素，不约束内容元素

- **装饰元素**（受母题约束）：`role: "decoration"` 或 `z_index` 落在装饰层 `10–19` 的元素，只能用登记的母题；
- **内容元素**（不受限制）：数据卡片、图表、表格、文字块、配图——该多还是多，不因母题规则被削减。

## 四、页间用法

- **不同页可以用不同的母题组合**，不必每页堆上全部母题；
- 封面 / 章节页用主母题做识别，内容页用次母题做边角点缀；
- 母题是点缀，不承担信息职能。

## 五、面积口径（硬约束）

同页所有**带 `motif` 标注的装饰元素**面积之和 ÷ 页面面积 **≤ 1/5（0.2）**。

- 页面面积 = `config.canvas.width_in × height_in`（13.333 × 7.5 in²，约 100 in²）；
- 口径为「元素面积直接求和」（重叠不重复扣减，偏保守）；母题面积超标即 `validate_plan.py` **error**，防止装饰抢内容。

## 六、元素的引用方式

在 `elements[]` 上加 `motif` 字段，值与 `design_brief.visual_motifs[].name` 一致：

```json
{ "type": "decoration_set", "set_id": "hand-drawn-lines", "role": "decoration",
  "z_index": 12, "motif": "叶脉线", "x_in": 11.6, "y_in": 0.6, "w_in": 0.9, "h_in": 0.9 }
```

## 七、检索与落地载体

- 装饰组库可直接作母题载体：`python scripts/find_asset.py --kind decoration_set <关键词>`；
- 也可自定义：用原生形状拼，或走生图 PNG（红线第 9 条允许的装饰例外）；
- 母题不做可编辑性要求（属装饰层）。

## 八、校验规则（`validate_plan.py`）

| 规则 | 级别 |
|---|---|
| 未声明 `visual_motifs` | info（建议按规范选定 3–5 种） |
| 数量不在 3–5 之间 / `visual_motifs` 非数组 | error |
| 主母题 ≠ 1 个 / 次母题不在 2–4 之间 | error |
| 条目缺 `name`、`name` 重名、`role` 非法 | error |
| 元素 `motif` 不在登记名单内 | error |
| 同页母题面积占比 > 1/5 | error |
| 母题标在非装饰元素上 | info（提醒：母题只约束装饰元素） |

## 九、正反例

| 情况 | 判定 |
|---|---|
| 3 种母题（1 主 + 2 次），封面用主母题、内容页交替用次母题 | ✅ 合规 |
| 声明了 6 种母题 | ❌ error：超过上限 5 |
| 声明 2 种母题 | ❌ error：不足下限 3 |
| 两个 `role: "primary"` | ❌ error：主母题必须恰好 1 个 |
| 元素写 `motif: "银杏叶"` 但名单里没有 | ❌ error：未登记的母题 |
| 一页把 3 种母题都堆上、面积占掉 1/3 | ❌ error：面积超 1/5 且堆叠过度 |
| 内容元素（数据卡片）也标了 `motif` | ⚠️ info：母题只约束装饰元素，内容元素不受限 |
