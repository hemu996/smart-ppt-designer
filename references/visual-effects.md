# 视觉效果素材生成规范

PptxGenJS 做不到的质感（烫金书法、辉光、纹样、粒子），**不硬磕**，统一用生图 PNG 作为装饰层嵌入。这是"视觉到位"与"可编辑"之间的务实折中，也是**红线第 9 条**的落点。

## 一、能用特效的四类效果

| 模板文件 | 效果 | 用在 | 预算/份 |
|---|---|---|---|
| `assets/effect-templates/gold-calligraphy.json` | 金色烫金书法标题 | 封面（优先），章节页 | ≤ 1 |
| `assets/effect-templates/glow-decor.json` | 发光装饰（光点/光带/光晕） | 章节页、数据强调页 | ≤ 3（单页 ≤ 1） |
| `assets/effect-templates/pattern-border.json` | 传统纹样边框/角花 | 国潮、人文主题 | ≤ 3 |
| `assets/effect-templates/tech-particles.json` | 科技粒子/网格背景 | 科技主题封面、数据页 | ≤ 2 |

`config.json` 的 `effects.max_per_deck` 默认 3；特效素材**不计入 3–5 张配图预算**，但总数同样要克制。

## 二、硬规则（违反即返工）

1. **特效只作装饰层**：标题文字、正文、数据、图表、表格必须仍是原生对象（红线第 10 条）。烫金标题图放在文本框下方，文字仍由文本框渲染。
2. **图层顺序（v5.2）**：特效素材属于 **L2 装饰层**，`z_index` 默认 `12`（区间 10–19）；绘制顺序为 L1 背景 → L2 装饰 → L3 内容 → L4 标题。特效永远在文字之下，且 `max(装饰 z_index) < min(内容 z_index)`（校验脚本会报 error）。
3. **透明底**：`gold-calligraphy` 与 `glow-decor` 必须透明背景。生图返回实底 → 按失败处理（改用 fallback），不要叠在页面上。
4. **不遮挡**：特效与文字框零重叠（`detect_layout.py` 会报遮挡）；装饰不承载信息，被裁掉也不影响理解。
5. **风格一致**：特效配色必须取自当前视觉系统；国潮系统才用纹样，科技系统才用粒子，**不要跨系统混用**。
6. **不加文字**：特效图内除主标题字形外不得出现其他文字。

## 三、调用方式

```bash
# 1) 生成待生图清单（含 prompt 模板展开结果、尺寸、透明度要求、目标文件名）
node scripts/generate_effects.js --plan output/plan.json --candidate A --emit output/effect_requests.json

# 2) 由 DSH 按 integrations/dsh-image.md 逐条调用生图插件，结果落到 output/effects/

# 3) 回填路径（写进页面计划的 effect_path / effects[] 字段）
node scripts/generate_effects.js --plan output/plan.json --candidate A --fill output/effects
```

页面计划里的写法：

```json
"effects": [
  { "template": "gold-calligraphy", "x_in": 0.9, "y_in": 2.45, "w_in": 8.6, "h_in": 1.6,
    "prompt_args": { "topic": "银龄中医药社区服务" }, "effect_path": null, "on_fail": "solid_title_bar" }
]
```

## 四、降级路径

| 效果 | 生图失败时 |
|---|---|
| 烫金标题 / 封面书法主标 | **无降级路径**（v9.0.3 强制）：生图失败必须重试或更换提示词，不得改成系统字体文本框、也不得改成色块标题条。生成不出来就停止交付并说明原因 |
| 发光装饰 | 改用原生圆环（donut）/细线，或直接省略 |
| 纹样边框 | 改用原生线条 + 方块拼简化回纹 |
| 粒子背景 | 改用纯色背景 + 原生细线网格 |

降级后必须在交付说明里写"第 X 页特效已降级为原生实现"。

## 五、自检清单

- [ ] 特效张数 ≤ `effects.max_per_deck`，单页 ≤ 1 处
- [ ] 所有特效图在文字图层之下
- [ ] 标题文字仍是原生文本框（可编辑）
- [ ] 透明素材背景透明、无实底残留
- [ ] 特效配色与当前视觉系统一致
- [ ] 特效与文字零重叠、不遮挡数据标签
- [ ] 降低分辨率预览后仍能看清标题（特效不能吃掉文字对比度）

## 六、v8.3 新增：四种高级视觉手法

| 手法 | 做法 | 实现方式 | 可编辑性 |
|---|---|---|---|
| **图片蒙版裁剪（半图半文）** | 用几何形状把图片裁成圆形 / 竖条 / 波浪，与文字并排融合 | 圆形、圆角：图片 `rounding` 参数；波浪、异形：**生图一张同色遮罩 PNG** 叠在图片上（遮罩法），或用形状遮住图片边缘 | 图片与遮罩属图片层；文字仍是原生文本框 |
| **文字填充效果** | 大标题 / 大数字用背景图纹理填充，而不是纯色字 | 由生图直接产出"带纹理 / 烫金的文字 PNG"（L4 标题层）。**不要**指望 PptxGenJS 给文字做图片填充 | 图片层、不可改文字（红线第 9 条允许的装饰例外） |
| **卡片静态动效** | 内容卡片带轻微投影 + 渐变边框，视觉上"浮起来" | 投影：形状 `shadow`；渐变边框：描边走 `primary→accent` 的 `gradFill`（构建脚本的 XML 后处理），或垫一张生图边框 PNG | 卡片仍是原生形状 + 原生文本 |
| **开场动画（可选）** | 24 片扇形组成整圆、顺时针由小变大，黑色扇形反向消失 | **不是构建脚本的活**：PptxGenJS 不支持逐帧动画。脚本只产出"起始帧形状清单 + 图层顺序 + 时长建议"，动画本身按 §七 的协作流程由人工完成 | 开场页其余内容仍原生 |

## 七、动画边界（v8.3 明确）

1. **默认不用自定义动画**：整份稿只保留"淡入"转场（章节页可用简单"推进"），与 §4.1.1"竞赛 PPT 以稳为主"一致；
2. **开场动画是可选特例**：仅在用户明确要求、且愿意人工微调时启用，并必须走完下面的协作流程；未走完不得计入交付；
3. **人机协作流程（4 步）**：
   1. AI 生成动画框架与静态起始帧（形状、图层顺序、时长建议）；
   2. **人工微调**关键帧、时长、图层顺序（PowerPoint 动画窗格）；
   3. 入库检验：流畅度、对齐、风格匹配度；
   4. 不合格 → 重新生成（最多 2 轮），仍不合格则退回静态版；
4. **诚实边界**：本包**不承诺**自动产出可播放的逐帧动画；页面能自动保证的是静态帧与统一转场。

## 八、自检补充（v8.3）

- [ ] 用图片蒙版时：裁剪后主体完整，遮罩色与背景同系，无生硬直边；
- [ ] 用文字填充时：该标题为图片层，同页正文仍原生可编辑；
- [ ] 卡片投影不超过 2 层、互不压制；渐变边框不产生"两套色"观感；
- [ ] 启用开场动画时：已确认用户明确要求、已人工微调并做过入库检验，否则退回静态；
- [ ] 全份转场仍统一为淡入（不混入花哨效果）。

## 九、烫金字实现细则（v9.0.2 补，规格 v9.3 §六）

烫金字**只用于标题**，且只有两处可用：
- ✅ **适用场景**：封面大标题、章节过渡页大标题（仅此两处）；
- ❌ **禁止场景**：正文、图表标注、页脚——这些一律不能用烫金字，必须是原生可编辑文本。

要求：

1. **实现方式**：由 `dsh.image` 直接生成「带烫金纹理的标题文字 PNG」（相当于手动版布尔运算相交），作 L4 标题层嵌入；**不要**试图用 PptxGenJS 做烫金 / 发光 / 渐变文字（红线第 9 条）。
2. **金箔素材要求**：细腻金箔纹理，**不要强反光**；**一整套 PPT 用同一张金箔风格**（不得每页换金箔），否则整份不统一。
3. **搭配要求**：**只在深色背景**（深红 / 深蓝 / 深棕）上用烫金字；浅色背景不要用。
4. **字体要求**：**粗体或书法体优先**；细字体做烫金会糊（笔画过细，纹理会吃掉字形）。

自检：

- [ ] 烫金字只出现在封面大标题与章节过渡页大标题；
- [ ] 正文 / 图表标注 / 页脚没有烫金字；
- [ ] 全份金箔风格一致（同一 prompt 家族或同一张纹理）；
- [ ] 烫金字所在页背景为深色系；
- [ ] 标题字体为粗体或书法体。
