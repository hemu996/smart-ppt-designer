# 封面生成规范

封面决定评委对整份 PPT 的第一判断。参考国赛/创赛水平封面：**整页背景大图 + 大字号标题 + 参赛信息行**。

## 一、封面的四层结构（v5.2）

封面是"多图层堆叠"最典型的页面，必须显式分层：

| 层 | 内容 | 实现 | `z_index` |
|---|---|---|---|
| L1 背景 | 全屏背景图 + 半透明蒙版（底色/渐变归此类） | 生图/图库图 + 蒙版矩形 | `0`（由 `image_path` 与构建脚本处理） |
| L2 装饰 | 金色书法标题、发光/纹样/粒子素材 | `effects[]` 生图 PNG | `12`（10–19） |
| L3 内容 | 副标题、参赛信息行 | 原生文本框 | `20–22` |
| L4 标题 | 主标题 | 原生文本框（装饰图只作底层） | `32`（≥ 30） |

> 关键：**装饰层永远在内容层与标题层之下**。若把烫金标题图放到主标题之上，主标题就不可读了——这在 v5.2 里属直接返工的问题。

## 二、必备四要素

| 要素 | 位置（13.333×7.5in） | 规格 |
|---|---|---|
| 背景图 | 整页 | 生图或免费图库，16:9，≥1600px 宽；叠加蒙版 |
| 主标题 | x 0.9 / y 2.6 / w 8.6 / h 1.3 | 28–36pt，白色或主题色，**原生文本框** |
| 副标题（一句话定位） | x 0.9 / y 4.0 / w 8.6 / h 0.7 | 14–18pt |
| 参赛信息行 | x 0.9 / y 6.35 / w 7.0 / h 0.4 | 12–14pt：参赛人 / 团队 / 日期（或"内部资料"等场合信息） |

模板见 `assets/layout-templates/cover-full-image.json`，卡片见 `knowledge/cards/cover-title.md`。

### 背景图与蒙版（承上：必备四要素的执行细节）

1. 背景图 prompt 必须写明**留白方位**，且留白方位与标题所在侧一致（标题在左 → "左侧大面积留白"）。
2. 背景图之后必须叠一层半透明蒙版（原生矩形 + `transparency`）：
   - 浅色图：透明 55–65；深色图：透明 65–75；
   - **验收要求：白字与背景对比度 ≥ 4.5:1**。这是首轮视觉校验的必改项——白字压在中灰蓝底（对比度约 3.2:1）在投影上会发灰。
3. 蒙版必须在所有文本之下（先加图片、再加蒙版、最后加文字）。
4. **推荐：左实右虚的自由渐变蒙版**（用户明确偏好，比整页均匀蒙版更高级）。
   文字在左、静物在右的封面：左侧 0–34% 保持 94%/91% 不透明，56% 降到 66%，
   76% 降到 28%，100% 全透明。左侧成为干净留白承托文字，右侧静物完整透出。
   实现用 `a:gradFill` + 每个 `a:gs` 内嵌 `a:alpha`，`a:lin ang="0"`（左→右）。
   **层序必错点**：蒙版要插在「背景图之后、书法图与所有文字之前」，
   插到最上层会把整屏文字盖成淡影。

## 三、视觉特效（可选，装饰层）

用 `assets/effect-templates/` 的模板生成 PNG 装饰层：

- `gold-calligraphy`：书法/烫金标题（国潮/红金主题优先，**默认飞白体**），每份 ≤ 2 处；
- `glow-decor`：发光装饰，仅章节页/数据强调页，单页 ≤ 1 处；
- `tech-particles`：科技粒子背景，科技类主题整页铺底。

**红线第 9 条**：禁止用 PptxGenJS 硬做烫金/发光/渐变文字效果，统一走生图 PNG。
v8.2 起允许标题本身由书法 PNG 承担 L4 视觉（图片层），但**正文、图表、表格仍必须原生可编辑**（红线第 10 条），
且同一份稿的标题书法风格必须统一（五型与 prompt 见 `../integrations/dsh-image.md`）。

## 四、章节过渡页：五要素标准结构（v8.2）

章节页不是"放一个『第二部分：项目背景』的大字"，必须有视觉设计。五要素：

| # | 要素 | 做法 | 落点 |
|---|---|---|---|
| 1 | 全屏背景图 | 与封面同风格、内容与章节主题相关 | `image_path`（L1） |
| 2 | 超大章节编号 | "01/02/03" 半透明大字作**背景装饰**，不是主要信息 | 构建脚本自动生成（120pt 半透明，L2） |
| 3 | 章节标题 | 大字号、醒目，**是唯一视觉焦点**（H2 28–32pt） | 原生文本框（L4） |
| 4 | 一句话说明 | 小字号副标题（H4 16–18pt） | 原生文本框（L3） |
| 5 | 装饰线条/元素 | 左侧或底部的金色/主题色装饰线 | L2 装饰层 |

约束：编号只作装饰、不得抢焦点；转场统一"淡入"（章节页可用简单"推进"）；
**整份稿的过渡页风格必须完全统一**；封面与章节页建议复用同一张背景图，或用同一 prompt 前缀生成的多张图。

## 五、结尾页（致谢页）规范（v8.2 新增）

结尾页不能是"左边白、右边图"的硬拼。国赛级标准：

1. **全屏背景图 + 渐变蒙版**：背景铺满整页，上盖半透明渐变蒙版（**左深右浅**，或标题同侧更深），
   文字直接压在图上；不要留白底拼图；
2. **大标题用飞白书法 PNG**：结束语/致谢语用书法字（L4 标题层），不是一行普通黑体；
3. **标配元素**：大字标题（一句话总结/致谢）+ 副标题（补充说明）+ 团队/参赛信息（左下或右下）
   + **至少 2 处装饰元素**（线条、角标、图标）；
4. **密度可低于内容页**：不必按内容页的 6–10 个元素，但**至少 5 个**
   （背景图 + 蒙版 + 大标题 + 副标题 + 团队信息 + 装饰）。

## 六、禁止事项

1. 把整页（含文字）做成一张图；2. 标题无蒙版直接压图；3. 封面堆目录或 3 个以上要点；4. 主标题超过 20 字；5. 封面出现两个以上强调色；6. 过度追求装饰忽略排版（3–5 个装饰元素点缀即可）。

## 七、超大字号层级（v8.7）

国赛稿的封面 / 目录 / 章节过渡 / 结尾页靠**远超内页量级的字号**制造冲击：素材库实测这些页最大字号落在 **187–287pt**，而本包内页标题只有 20–44pt。本包据此建立两级字号体系：

| 页面 | 角色 | 字号区间 | 说明 |
|---|---|---|---|
| 封面 | 主标题 | **120–287pt**（`fonts.display_size`） | 目标 ≥187pt；竖排或日式排版可到 200pt+ |
| 目录页 | 主标题 | 120–287pt | 与封面同量级，配编号卡 |
| 章节过渡页 | 章节标题 | 120–287pt | 与超大半透明编号（100pt+）区分主次：标题是焦点、编号是装饰 |
| 结尾页 | 结束语 / 致谢 | 120–287pt | 若视觉焦点由书法 PNG 承担，原生标题可退到 36–44pt，但整页**至少有一处 ≥187pt 的视觉焦点** |
| 内页（内容 / 数据） | 页标题 | 仍守 `page_title_size`（20–24pt） | 不放宽 |

约束：

1. **字号跨度**：整份稿 `最大字号 / 最小字号 ≥ 5.7×`（素材库实测 5.7×–31.9×）—— 靠"封面特大 + 内页小字说明"拉开层次，不是把正文放大；
2. **不越出画布**：200pt 标题约需 ≥3.8in 框高（估算器按 1.35 行距推算），约半屏，标题框必须落在安全区内；
3. **一页一焦点**：超大字号是唯一焦点，同页不得再有同量级字号（红线 17）；
4. `validate_plan.py`：封面 / 目录 / 章节 / 结尾页的 `title` 字号上界放宽到 `display_size` 上界；耀眼版下这些页最大字号 <187pt 给 warning；
5. `score_deck.py`「国赛对齐度」把 `封面/章节页最大字号 ≥187pt` 与 `字号跨度 ≥5.7×` 作为两个独立子项打分。

## 七、封面 AI 书法主标（**强制**，v9.0.3 起不可关闭）

> **冲突裁决**：第二节「主标题用原生文本框」是通用默认；`config.cover_title.mode = "ai_calligraphy"` 时以本节为准。
> **用户 2026-11-08 明确要求「以后 PPT 封面强制使用 AI 生成的书法体」**，升级为硬约束：
> `config.cover_title.enforced=true`、`allow_fallback_to_text=false`。
> 三层拦截：① `validate_plan.py` 缺图/存在系统字主标 → **error**；② `build_pptx.js` → **抛错退出，不产出残稿**；
> ③ `visual-effects.md` 降级表删去烫金标题的降级路径。**生图失败只能重试或换提示词，不得降级为系统字或色块标题条。**

1. **主标必须是 AI 生成的图片**：透明底书法 PNG，系统字体不算达标。
2. **仅此一处可为图片**，封面其余文字必须原生可编辑。
3. **禁止重影**：主标用图片后不要再叠同文本文本框。
4. **配色按底色定，不固定金色**：亮米白底用深靛蓝 #1A3A5C（WCAG 6.5）或墨褐 #1F1B16（9.5）；
   金 #C9A227 在亮底仅 1.38，禁止直接用。深底才用金。
5. **白底转透明要按真实背景亮度归一化**：生图背景常是 238–245 而非 255，
   用 `(255-lum)` 会让背景残留约 9% 不透明，整块矩形蒙上一层淡色。
   正确做法：取四边中位亮度 bg，`alpha=(bg-lum)/(bg-40)*255`，再 `alpha<28 → 0`。
6. **验收**：渲染后书法区 WCAG ≥ 4.5、墨迹占比 ≥ 15%。
7. **不可绕过**：不要通过把 `mode` 改成别的值、或删掉 `enforced` 来关掉这条；这是用户级约束，不是可选开关。

提示词模板见 `assets/calligraphy-prompt.md`。
