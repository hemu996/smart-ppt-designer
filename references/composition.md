# 页面构图两硬约束（v8.9，用户指定）

两条**硬约束**（校验器 `error` 级，任一条不满足即返工），目标是破除"元素大小相近、平铺对齐"的沉闷版面。
第 3 条「错落感」经用户确认**不启用**：相关阈值、校验与手法已从本包移除，不要按它排版。

## 一、① 大小对比：每页至少 1 个超大元素

- 口径：页面面积 = 13.333 × 7.5 = 100in²；**每页至少 1 个非装饰元素的面积 ≥ 页面面积的 1/3（33.3in²）**；
- 不计入判定：`role = decoration` 的元素、装饰组、以及 `role = background` 的底；
- 常用做法（按版式）：

| 版式 | 超大元素 |
|---|---|
| 内容页（sidebar-nav / data-dashboard / four-grid） | 半版**背板**（x 1.45 / y 1.50 / w 11.25 / h 4.50 ≈ 50.6in²，深色半透明 + 金色细描边） |
| 出血大图页（image-bleed） | 右半版大图（5.683 × 6.28 ≈ 35.7in²，天然满足） |
| 封面 / 章节 / 结尾页 / 目录页 | 同上统一背板（避开左侧轨道与右侧标尺） |

- 反例：一页全是字号相近的文本框与同尺寸卡片——观感"文档化"，评委 3 秒内找不到重点。

## 二、② 叠压关系：每页至少 2 个元素前后叠压

- 口径：两个非装饰元素**几何重叠面积 > 0.15in² 且 `z_index` 不同**，即构成一对"前后叠压"；每页至少 1 对（= 2 个元素）；
- 规范做法：内容压在背板之上——背板 `z_index` 13（高于装饰组 10–12、低于内容 20+），内容 20–29，标题 30–39；
- 边界（红线第 11 条仍然有效）：**文字不得被压在下面而不可读**；"色块完整托住文字"与"大衬底在下、小元素在上"由 `detect_layout.py` 记为 info，"文字被遮 15% 以上"仍是 error；
- 反例：所有元素互不重叠、平铺在网格里——版面没有纵深。

## 三、校验与自检

| 落点 | 说明 |
|---|---|
| `validate_plan.py` | 两条检查均为 `error`：① 最大内容元素面积占比 ② 叠压对数（面积 >0.15in² 且 z 不同） |
| `config.composition` | 阈值集中在此（`min_big_element_area_ratio` / `min_overlap_pairs` / `min_overlap_area_in2`） |
| `detect_layout.py` | 按绘制顺序判"衬底叠压""色块托字"为 info，"文字被遮"为 error |
| 构建日志 | 装饰组 / 组件 / 创意度 / 字体声明行可直接对照本页是否落了大块与层叠 |

## 四、与既有口径的关系

- 与"留白率 ≥35%"（`advanced-design.md`）：加背板会降低留白率，两者需权衡——**优先满足本文件的两条硬约束**，留白率作参考项（示例稿实测 0.245，属已知差距）；
- 与"12 列网格对齐"（`evaluation-rubric.md` 第 4 项）：本约束**不**要求元素偏离网格，元素仍应吸附 12 列网格；
- 与"红线 17 一页一焦点"：超大元素（背板/大图）承担"体量焦点"，`metric` 大数字承担"数值焦点"，两者不冲突。

## 五、去 AI 感：手工感装饰与卡片差异化（v8.9）

成稿"像 AI 做的"通常出在两处：版面太完美（元素等大、全平铺、角度全 0）与卡片全一样。两条改法。

### 5.1 手工感装饰元素（贴纸类装饰组）

| 装饰组 set_id | 形态 | 建议用法 |
|---|---|---|
| `hand-drawn-lines` | 4 段短线角度 −1.8°~+2.2° 不一、粗细 0.7–1.7pt、端点错开 + 2 笔触点 | 标题下强调线、要点下划线 |
| `stamp-seal` | 空心圆环 + 内短横 + 外框 + 小点，整体 ±6°–9° 偏斜 | 右下角"盖章"，每份 ≤ 2 处 |
| `sticky-note` | 半透明便签 + 右下折角 + 两条示意线，−3° | 左下角贴纸，示意"提示 / 备注" |
| `paper-tape` | 半透明胶带条 12° 斜贴 + 两侧压边 | 压在图或背板边缘，模拟贴纸 |
| `hand-arrow` | 两段折线（−4° / +3°）+ 箭头短线 + 起点圆点 | 指向数据或结论做手绘标注 |

用法：与框架类装饰组混用（内容页装饰组总量仍是 2–3 组），一份稿里手工感元素 ≤ 4 处，避免"贴纸满墙"。

### 5.2 倾斜的边界（与规格"禁止倾斜/穿插"的关系）

- **贴纸类装饰**允许 ≤12° 轻斜（印章 / 便签 / 纸胶带 / 手绘线条 / 手绘箭头），这是"手工感"的来源；
- **其余一律水平垂直对齐**：正文、卡片、图片、图表、框架类装饰、背板角度必须为 0，不得随意偏移或穿插；
- 破局感优先靠"1 个元素稍微超出卡片 / 背板边框"（超出 0.1–0.3in）实现，而不是把整页元素转角度。

### 5.3 卡片差异化（同页不得全同）

- **形态混用**：同一页卡片至少出现 2 种形态——直角（矩形）、大圆角（`roundRect`，圆角 ≥0.28in）、细描边款（无填充 + 1pt 描边）；
- **大小分级**：主卡（≥ 页面面积 1/6）1 张，次级卡 ≥2 张，两者尺寸不完全相同；
- **左上角序号**：每张卡左上角留 0.5 × 0.1in 的序号带（`accent` 色），是国金稿的共通特征；
- 校验：同页出现 ≥3 张"形态 + 尺寸完全相同"的卡片时，`validate_plan.py` 给 warning（卡片同质化）。

### 5.4 标题个别字放大

- 标题里把 1–2 个关键字放大：`el.runs` 富文本（`[{"text": "...", "fontSize": N, "bold": true}]`），关键字字号 ≥ 正文 1.4×；
- 一页一焦点（红线 17）仍然有效：关键字放大不等同于新增第二个焦点，整页最大字号仍只属于标题本体；
- 示例：正文 24pt 的标题 "三大结构性痛点" → `runs = [{"text":"三大"},{"text":"结构性","fontSize":34,"bold":true},{"text":"痛点"}]`（34/24 ≈ 1.42×）。
