# 封面人物形象替换法（用户 2026-11-10 口述，v9.0.6 纳入）

> **适用场景**：套用模板 / 复用一张现成封面时，**封面上的人物形象不对**（不是我们的人、性别/年龄/身份/职业不对、气质不对），需要换一张，但又要保持原来那张的"级别"和融进去的感觉。

## 一句话

**不要直接改 prompt 换个人**。先把原图"读"成描述 → 归到类别 → 用**同一个类别的文案**去生成，这样新图和原图才在同一个级别上，不会一个像摄影一个像插画、一个专业一个随意。

## 五步（必须按序，不许跳）

### 1. 读图
用图像理解（DSH `read_image` / qwen-vision 等）打开**原封面**，只读这一张。

### 2. 拆人物描述
把"人物形象"拆成可复用的维度，逐项写下来，**不要笼统写"一个人"**：

| 维度 | 要写清 | 反例 |
|---|---|---|
| 身份/角色 | 学生 / 工程师 / 医生 / 农民 / 讲解员 | "人" |
| 人数与站位 | 单人 / 群体；居中 / 偏左 / 远景 | "有人" |
| 年龄与性别 | 青年女性 / 中年男性 / 儿童 | 不写 |
| 着装与道具 | 白大褂+听诊器 / 学位服 / 工装+安全帽 | "穿衣服" |
| 姿态与视线 | 站立讲解 / 俯身操作 / 看向镜头 | "站着" |
| 光线与画质 | 逆光暖调 / 棚拍硬光 / 纪实抓拍 / 插画平涂 | "清楚" |
| 背景关系 | 虚化教室 / 纯色 / 场景融合 | "有背景" |
| 构图占比 | 人物占画面 1/3 / 半身 / 只露局部 | 不写 |

### 3. 归类
把上面这些维度**归到一个类别**，而不是归到某个具体人。类别是两个东西的组合：

- **人物类别**（决定"是谁"）：如「青年工科学生·实验室」「乡村青年·田间」「医护·临床」「非遗传承人·作坊」
- **视觉级别**（决定"多高级"）：如 `摄影级·棚拍` / `摄影级·纪实` / `国潮插画·工笔` / `扁平矢量` / `3D 渲染`

> 这两层要分开。**级别错了比人物错了更致命**：人物对了但画成卡通，整页立刻塌。

### 4. 用类别文案生成
用**第 3 步的类别**去写 prompt，而不是"把原图那个人换成 XX"。

```
[类别] 青年工科学生·实验室，摄影级·棚拍
[维度回填] 单人、半身、居中偏右、白大褂+护目镜、俯身看设备、柔和侧光、
           实验室虚化背景、人物占画面 1/3、不出现文字
[风格续用] 与本稿封面同一套色系 / 同一留白方位 / 同一质感
```

- 必须带上 `references/image-strategy.md` 的**融入三判据**（主题对应 / 风格续用 / 不抢戏）；
- 必须复用同一视觉系统的 `image_style` 前缀；
- **画面内不出现文字、不出现写实人物以外的杂物**（和本包既有口径一致）；
- 若原模板封面是**真实照片**，新图也必须是照片级，不能降成插画；反之亦然。

### 5. 保同级效果（验收，不能凭"我觉得挺搭"）
新图生成后，与**原封面并排核对**，逐项确认：

- [ ] 人物类别对（是我们要的人，不是原模板里那个人）
- [ ] **视觉级别与原图同档**（摄影↔摄影、插画↔插画、写实↔写实）
- [ ] 光线/画质/颗粒感同档（不能一个棚拍一个手机抓拍）
- [ ] 色系、留白方位、明暗档位与本体一致（亮底仍亮底，禁深色）
- [ ] 构图占比相当（人物别突然放大或缩成一小点）
- [ ] 叠上封面蒙版后，书法主标与文字对比度仍达标（亮底禁纯金字）
- [ ] 交付说明写明：原图读到什么、归了哪类、新图用了哪条类别文案

任何一项不过 → **重生成或改回类别**，不要将就。这一条就是"保证在同一个级别的效果"。

## 与既有规矩的关系

- 本法**不替代**红线 28：封面主标仍必须是 AI 书法 PNG，换的只是**人物形象/底图**；仅该主标为图片，其余文字原生可编辑。
- 本法**复用** `references/image-strategy.md` 的融入三判据与缺图四级优先（先复用本稿原图 → AI 补图 → 图库 → 纯色）。
- 本法**归属**在模板填充模式（`template_mode=fill`）：见 `references/user-templates.md` 六步流程第 2 步；自由生成时若封面人物不对，同样按本法走。
- 不需要新图时（原图里人物其实可用）→ 直接复用，别为了"换"而换。

## 素材从哪找

`ppt-assets/` 已按类别编目（见 `assets/ppt-assets-catalog.json`）。检索：
```bash
python scripts/find_asset.py --kind ppt_asset 人物
python scripts/find_asset.py --kind ppt_asset 非遗
```
先在本机素材里找**同类别、同级别**的现成图，找不到再走第 4 步生成 —— 这才是"比较方便的调用"。
