# 复杂布局模板库

高密度信息页是"看起来专业"的关键。模板定义在 `assets/layout-templates/`，页面计划里的 `layout_template` 字段引用模板名。

## 一、四个模板

| 模板 | 适用 | 关键要求 |
|---|---|---|
| `sidebar-nav` | 项目背景、技术创新、方案说明 | 左侧 1.18in 导航栏 + 单页 2–4 个模块 |
| `four-grid` | 痛点分析、优势对比、四项并列举措 | 四格等大，格内结构一致 |
| `data-dashboard` | 市场分析、核心指标、试点成效 | 指标卡行 + 原生图表 + 原生表格/要点 |
| `cover-full-image` | 封面、章节过渡、结尾 | 整页背景图 + 蒙版 + 大标题 + 信息行 |

模板文件给出 `zones`（各区域 x/y/w/h）与 `typography`（字号区间）。**页面计划的元素坐标应当落在模板 zone 内**，越出 zone 会被视觉校验视为不对齐。

## 二、怎么选

1. 有 3 个以上并列模块、且需要评委随时知道进度 → `sidebar-nav`；
2. 恰好 4 个平级模块（痛点四条、优势四点）→ `four-grid`；3 个模块不要硬凑四宫格，改用 `sidebar-nav` 或 `data-dashboard` 的 3 卡布局；
3. 页面要同时出现"数字卡片 + 图表 + 明细" → `data-dashboard`；
4. 封面/章节页/结尾页 → `cover-full-image`。

## 三、高密度但不拥挤的 6 条纪律

1. **一页一个结论**：模块再多，也要能在标题下一句话读完主张；`claim` 字段就是这句话。
2. **模块数上限**取自视觉系统 `density.max_modules_per_page`（默认 5–6）；同页模块数量超过上限，先删信息再谈排版。
3. **模块内部结构一致**：都有"图标 + 小标题 + 2–3 条要点"，不要一个模块是图、一个是表格、一个是段落。
4. **要点字数**：每条 ≤ 20 字，每模块 ≤ 4 条；超了拆页，不要缩字号。
5. **图标节流**：一页 ≤ 4 个图标（首轮视觉校验结论：图标过多会削弱层级）。
6. **留白对冲**：高密度页底部留白 15–20% 即可；不要把内容硬塞到贴边，也不要留出 30% 以上空白。

## 四、模板与卡片的配合

布局模板解决"页面骨架"，设计卡片（`knowledge/cards/`）解决"这类内容该用什么结构"。两者同时用：

- `sidebar-nav` + `layout-sidebar-nav` 卡片：骨架与结构规则一致；
- `four-grid` + `layout-four-grid` 卡片；
- `data-dashboard` + `layout-data-dash` 卡片（含原生图表/表格要求）；
- `cover-full-image` + `cover-title` 卡片。

卡片里的"反例"优先级高于模板：例如 3 个对象不得用四宫格，即改用 `data-dashboard` 的 3 卡布局。

## 五、新增模板

复制最接近的模板文件，改 `name/label/use_when/zones/slots`，并在 `layout-templates.md`（本文件）的表格里登记；随后跑一次端到端构建，确认新 zone 坐标不与导航栏冲突。
