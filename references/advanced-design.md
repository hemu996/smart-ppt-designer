# 高级设计原则与量化口径（v8.8 新增）

把公开设计方法里**能落地、能量化**的部分收进来，作为版式、留白、对比、图表与文字节奏的补充口径。
凡与 `visual-system.md` / `layout-templates.md` 已有规则冲突，以本文件更严的值为准；本文件的口径同步写进
`config.json:advanced_design`，`score_deck.py` 的「国赛对齐度」与 `validate_plan.py` 按此口径体检。

## 一、版式四原则（亲密 / 对齐 / 重复 / 对比）

| 原则 | 含义 | 在本包怎么落地 |
|---|---|---|
| 亲密 | 相关元素靠近成组，无关元素拉开 | 同模块元素间距 ≤ `0.3in`；模块之间 ≥ `0.55in`（**组间距 ≥ 组内间距 × 1.8**） |
| 对齐 | 任何元素都与其他元素有视觉联系 | 一律吸附 12 列网格与页边距基线；禁止"假对齐"（差 1–2pt 的错位比不对齐更糟） |
| 重复 | 同一功能用同一视觉语言 | 用「组件」跨页复用（导航、卡片、编号块、图例条），不逐页重画；同层级字号/色/图标风格全篇一致 |
| 对比 | 让不同的更不同 | 层级字号跨度 ≥ 1.6×（标题:正文），关键数据用 `metric` 40–60pt 拉开 |

> 判据：一页里若出现"两个同量级焦点"或"三处以上同级留白不均"，即判对比不足（对应红线 17）。

## 二、网格：三分线 + 黄金分割

- 纵向：画布 13.333in 按 12 列（列宽 0.983in、列距 0.2in）——已在本包 `config.grid` 固定；
- 横向参考线：`38.2%` 与 `61.8%`（黄金分割）为"标题带 / 内容带 / 结论带"的分界；
- 视觉重心优先落在**三分线交点**（x 4.44 / 8.89，y 2.87 / 4.63）；
- 元素坐标一律取整数到 `0.01in`（像素级精切），避免 0.003in 级假对齐。

## 三、留白：留白 ≠ 空白

- 定义：**去掉不必要的装饰后，元素之间、段落之间保持的空间感**，不是"留白颜色"；
- 目的有二：**突出主题**（对象周围留白越多，注意力越聚焦）与**建立层次**（用间距分组，替代用线条分组）；
- 量化口径：内容页**非元素面积占比 ≥ 35%**（即留白率 ≥ 35%，封面上限放宽到 30% 下限）；
- 反例：把空白用装饰填满以"显得丰富"，直接拉低信息传递效率（红线 19 的点缀型装饰占比即为此设）；
- 实测方式：本包按「元素面积和 ÷ 内容区面积」估算（重叠部分重复计入、装饰组与配图不计），因此实测值偏保守，作为**下限**用于趋势判断；示例稿实测 0.245–0.30，说明内容页仍偏密，属已知差距。

## 四、对比三法：字号 / 颜色 / 字体

1. **字号对比**（主力）：层级之间 ≥ 1.6×，如页标题 24pt → 正文 14pt（1.71×）；
2. **颜色对比**：同一版式只允许 1 处高饱和强调色（`accent`），其余走中性；一套稿**主/辅/强调/中性 ≤ 4 色**（与"色数/页 ≤12"并行：4 色族 + 明度变化）；
3. **字体对比**：一份稿**至多 2 个字体族**（标题/正文各一），靠字重与字号分层，不靠换字体。

## 五、图表：五步化简 + 数据墨水

1. **精简元素**：关掉网格线、坐标轴线、默认图例；图例确需保留时移到文字侧、水平排列；
2. **统一配色**：主色（数据）+ 辅色（对比项）+ 强调色（结论项）+ 中性色（其余），禁用默认彩虹色；
3. **字体分层**：图表内文字只用一个字体族，标题 11–12pt、标签 10–11pt、数据标签按需加粗；
4. **质感克制**：仅当"颜色绑定数值"时才用渐变；不用阴影、重描边、3D；
5. **数据墨水比**：代表数据的像素应是视觉中心——轴标签用浅灰、数据线/柱用主色，背景与网格退到最后。

> 本包原生图表由 `scripts/build_pptx.js` 统一取 `visual_system.chart_palette` 与 `text/text_light` 上色，已默认关网格线；
> 改配色请改视觉系统的 `chart_palette`，不要逐图硬编码。

## 六、文字节奏：负空间与字数上限

- 行距 1.3–1.4、段距 ≥ 0.5 倍行距、字距不手动压缩；
- **每页正文 ≤ 180 字**（约 75 个英文词，超过即成"文档"而非幻灯片）：`config.layout_thresholds.max_chars_per_textbox = 180`；
- 一页一个主张（`claim`），其余信息降级为支撑点或转入备注；
- 讲者备注写"怎么讲"，不写"页面有什么"（红线 14）。

## 七、量化口径速查

| 指标 | 口径 | 落点 |
|---|---|---|
| 组内间距 / 组间间距 | ≥ 1 : 1.8 | 计划元素坐标（亲密） |
| 层级字号跨度 | ≥ 1.6× | `fonts.*` 层级 |
| 色族数 / 页 | ≤ 4（主/辅/强调/中性） | 视觉系统 + 校验器色数 ≤12 |
| 留白率（内容页） | ≥ 35% | `score_deck.py` 逐页体检（info） |
| 正文量 / 页 | ≤ 180 字 | `max_chars_per_textbox` |
| 字体族 / 份 | ≤ 2 | 字体白名单 |
| 图表网格线 / 3D / 阴影 | 0 | 构建层强制 |
