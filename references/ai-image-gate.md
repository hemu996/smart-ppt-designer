## G-AI 质检闸门（开工前必跑）

### 第 1 步：生图能力是否可用

| 检查项 | 怎么查 | 通过判据 |
|---|---|---|
| 生图工具在不在 | 调一次 `image_generate`（哪怕小图） | 返回了文件路径 |
| 输出落在哪 | 看返回的 `saved` 路径 | 拿到真实绝对路径 |
| 支持的尺寸 | 只能 1024×1024 / 1024×1536 / 1536×1024 / auto | 选定一个 |
| 是否支持参考图 | `referenceImages` 参数 | 需要贴合模板时用它 |

**不通过就停**：退回用模板原生元素或用户实拍，不硬造。

### 第 2 步：先读原元素，再写提示词

**不许先写提示词。** 顺序必须是：

1. **定位原元素**：它是文字、形状、还是图片？在哪个 part？什么坐标尺寸？
2. **看它周围**：底色、相邻装饰、光效、圆角、描边、投影、饱和度。
3. **提取视觉语言**：主色 hex、辅助色 hex、明度、材质（扁平/玻璃/写实 3D/线描）、装饰母题。
4. **写提示词**时把这套语言写进去：
   - 颜色用 hex 明确指定（如 `deep navy #0C2D5F`）
   - 明确 `no text, no letters, no watermark`
   - 明确背景处理（透明底 / 同色底 / 白底待抠）
   - 明确构图（横条 / 竖版 / 方形 / 出血方向）
5. **尺寸必须匹配原元素比例**，否则插入后变形。

### 第 3 步：生成后必须肉眼质检

生成完**先自己看**，逐条核对：

- [ ] 主色与模板是否同一色系（不是"差不多"，是能并排看）
- [ ] 材质与模板是否协调（模板是玻璃光感，就不能给扁平插画）
- [ ] 有没有文字/水印/乱码（AI 常出错字）
- [ ] 构图留白是否够（会不会压住文字）
- [ ] 插入位置会不会盖住其他元素（先算坐标再放）
- [ ] 缩放后是否还清晰（别用小图拉大）

**任一条不过：重生成，不许将就。**

### 第 4 步：插入前先算清叠压关系

模板底部/边角的元素经常是**多层叠压**（底图 + 装饰组 + 文字组）。
插入前必须：

1. 列出该区域所有元素（pic / sp / grpSp）及其 z 序
2. 确认新元素插在哪一层
3. 确认不会盖住导航文字等不可动元素

## 本次踩过的坑（写下来防止再犯）

| 坑 | 症状 | 正确做法 |
|---|---|---|
| 用 PIL 画文字条冒充设计 | 僵硬、和模板不搭 | 用 AI 生图或原生形状 |
| 把整条底图当品牌位替换 | 导航文字被覆盖、出现乱码叠字 | 先拆解：底条 / 左导航组 / 右品牌组 是三个部件 |
| 提示词没写模板色 | 生成图色系不搭 | 提示词里写死 hex |
| 裁切比例没算 | 元素只剩局部 | 先算目标显示比例，再决定裁切区 |
