**结论**：公开可直接下载的**国赛优秀 PPT 原件**在本次检索范围内不可得（验证码 / 网盘 / 关注 / 付费四类阻断）；因此不把"网上找案例"当成素材来源的主路径，改为：**用户案例图（观感基准）+ 官方口径（内容骨架）**。

## 三、从公开来源提炼的内容骨架（官方口径，可直接用于写计划）

路演/项目 PPT 的内容顺序（河南科技学院教务处口径）：

```
项目概述 → 产品/服务介绍 → 市场分析及定位 → 商业模式 → 营销策略
        → 财务分析 → 风险控制 → 团队介绍（+ 实物展示位）
```

校赛材料要求（沈阳工业大学口径）：项目简介、市场分析、技术说明、应用场景（案例）、商业模式、团队介绍、实践过程。

用法：写页面计划时，把上述条目按"金字塔叙事 + 行动标题"落到 A/B 两套候选；缺哪一项在交付说明里注明（评委会看结构完整性）。

## 四、后续取数策略

1. **优先用户提供**：新案例图直接放入 `assets/target-cases/` 并在其 README 登记；
2. **官方口径持续核实**：每年大赛通知的赛道/材料/时间要求，纳入本节第三部分；
3. **原件下载仅在可直连时执行**：遇到带验证码、网盘、付费墙的来源，记录链接与原因，不尝试绕过；
4. 涉及第三方版权的内容（案例截图、模板原件）**只在包内本地留档**，不对外分发。
