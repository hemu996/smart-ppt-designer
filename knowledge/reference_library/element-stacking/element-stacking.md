# 元素堆叠方式与视觉节奏（样本实测，v8.0 新增）

规格 v8.0 明确：素材库的学习目标**不只是配色，核心是排版与元素堆叠**——学"同一页里叠了几层、每层是什么、
透明度怎么处理、AI 装饰件与原生内容怎么混"。本文件按 8 份样本 136 页实测回答这三个问题。

数据来源：`python scripts/analyze_reference.py --ref-dir assets/sample-ppts`（逐页 `图层顺序` 字段可得）。

## 一、标准四层 ↔ 样本实测的对应

| 层 | 内容 | 实现 | 样本实测（136 页） |
|---|---|---|---|
| **L1 背景层** | 全屏背景图 / 渐变底色 / 纯色 | 生图 或 纯色填充 | **最底层是整页图片的 78 页（57%）**；是形状（铺底色块/渐变）的 42 页（31%）；是组合（背景装饰组）的 15 页（11%） |
| **L1.5 蒙版** | 背景太花时压一层半透明蒙版 | 半透明矩形 | 满图型页面必备（本包要求白字压图对比度 ≥4.5:1） |
| **L2 装饰层** | 纹样边框、发光元素、粒子、侧边条 | 生图 PNG（透明背景） | 每页图片均值 **7.8** 张、且"占画布 ≥25% 的大图占比≈0" → 绝大多数是**小尺寸装饰件** |
| **L3 内容层** | 文本框、图表、表格、数据卡片、图标 | 原生对象 | 每页形状均值 **30.9** 个（最多 164）、文字均值 **175** 字（最多 733） |
| **L4 标题层** | 大标题（书法 PNG）或原生文本 | 生图 PNG 或原生文本 | 每页最大字号均值 **50.7pt**（最高 256.8pt） |

## 二、元素密度：样本几乎每页都是"多层堆叠"

- 元素量（形状 + 图片）**≥10 的页面占 89%**（121/136）——不存在"一行标题 + 两行字"的裸页；
- 每页**组合（group）均值 7.7** 个（最多 42）→ 装饰件与图标做成**组**，一次做好、多页复用；
- 对照组：本包 `density_modes.concise` 要求 3–5 个元素，`vivid` 要求 6–10 个，
  **样本的 30+ 元素属于"设计源文件级密度"**，不要照抄；本包只要做到"每页有层次、焦点明确、装饰 ≤1/3"即可。

## 三、图层顺序高度多样：逐页设计，不是套固定顺序

- 136 页里出现了 **100 种以上不同的图层顺序**，出现最多的一种也仅 2 页；
- 典型形态：`图 → 形×2 → 图×2`（满图底 + 色块 + 装饰件）、`图 → 形×6`（满图底 + 多色块）、`组 → 形 → 组×3`（组合复用）；
- 结论：**不要指望一个固定的层叠顺序走完全篇**。本包的做法是——每页元素显式声明 `z_index`，
  按"背景(0) → 装饰(10–19) → 内容(20–29) → 标题(30–39)"**升序绘制**，顺序由数据决定，而不是靠模板顺序。

## 四、透明度与混叠处理

- 本包现行规定（样本未逐元素统计透明度，以下为规范值，不要当成实测值）：
  - L2 装饰件：**50–80%**（浅纹样 70–80%、发光线条 50–60%）；
  - 满图背景上的文字蒙版：**55–70%**（白字压图必须实测对比度 ≥4.5:1）；
- AI 装饰件与原生内容的混叠原则：**装饰在下、内容在上**，装饰不得遮挡文字（红线 11）；
  装饰件一律走 `assets/effect-templates/` 的四类提示词，不要临场编风格。

## 五、视觉节奏（页间密度交替，不能每页都塞满）

样本的角色序列规律（8 份一致）：

```
封面 → 密集内容页/内容页（主体）→ 数据页 / 图主导页 穿插 → [结尾页]
```

- 136 页中：数据页 **18** 页、图主导页 **10** 页（合计约 **21%**），其余为内容类页面；
- 节奏建议：**每 3–5 页出现 1 页"低密度页"**（数据页、图主导页或章节页）来换气，
  不要让读者连续看 6 页以上同密度的多模块页；
- 封面 / 章节页 / 结尾页承担"大留白 + 大字号"的角色，与内页形成对比。

## 六、照抄与不照抄

| 可以照抄 | 不要照抄 |
|---|---|
| L1 打底方式（满图 / 渐变 / 纯色 三种） | 30+ 元素的绝对密度（本包 `vivid` 上限 10） |
| 组合复用装饰件的做法 | 每页色值最高 12.3 的用色量（本包收 6 色） |
| 逐页设计层叠顺序的思路 | 0 文本框的整页图片页（红线禁止，见 `../../fail_cases/fc-20261105-01.md`） |
| 数据页 / 图主导页的换气节奏 | 空备注（样本 8 份备注全为空） |
