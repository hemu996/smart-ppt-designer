# 布局模式（从样本实测）

依据 8 份样本 136 页的逐页结构与卡片映射。**"映射到已卡片化结构"= 126 / 136 页（93%）**，
说明样本的页面形态本包基本都能承接；剩下的主要是"整页图片页"（10 页）——本包红线禁止。

## 一、样本通用的页面骨架序列

```
封面 → 章节过渡 → 多模块内页 ×N → 数据页（指标卡 + 图表/表格） → 结尾
```

- 样本内页角色分布（136 页）：多模块内页 **84**、数据页 **18**、封面/章节/结尾 **16**、整页视觉 **10**、单点指标 **6**、双栏 **2**。
- 内页占绝对多数（62%），且几乎都是"多模块 + 文字块"结构。

## 二、六种可复用布局模式

| # | 模式 | 样本依据 | 本包对应 |
|---|---|---|---|
| 1 | **多模块卡片页**（3–4 模块并列，每模块"图标 + 小标题 + 2–3 条要点"） | 84/136 页；形/页 21–59、组/页 3.9–21.6 | `sidebar-nav` / `four-grid` 版式 + `layout-sidebar-nav` / `layout-four-grid` 卡片 |
| 2 | **数据页**（指标卡行 + 原生图表或原生表格） | 18 页；6 份样本有表页、5 份有图页，各 1–5 页 | `data-dashboard` + `layout-data-dash` |
| 3 | **大背景封面/章节页**（整页底 + 大字 + 一句说明） | 16 页；最大字号可达 80–287pt | `cover-full-image` + `cover-title` 卡片（封面/章节同构） |
| 4 | **单点指标页**（一页只钉一个关键数字） | 6 页（非遗乐器 4、刺绣文化 2） | `metric-highlight` 卡片（数字 40–60pt + 说明 12–14pt） |
| 5 | **双栏对照页**（恰好两个平级对象） | 2 页 | `layout-two-column` 卡片（对象 ≥3 禁用，改 `comparison-matrix`） |
| 6 | **图主导页**（文字 ≤80 字，图片承担主视觉） | 10 页整页视觉（除 Airflow 的 33 页） | `image-strategy.md` + `cover-full-image`；**不得**输出 0 文本框的整页图片页 |

## 三、密度区间（照抄时的合理范围）

| 指标 | 样本区间 | 建议取值 |
|---|---|---|
| 每页形状数 | 21–59 | 25–60（不含组合内部元素重复计数） |
| 每页组合数 | 4–22 | 装饰件与图标做成组合复用 |
| 每页图片数 | 5–15 | 装饰件为主，不塞照片 |
| 每页字数 | 114–219 | 内页 120–200；数据页可低至 80 |
| 每页色值数 | 3.1–12.3 | **本包收敛到 ≤6**（见 `../decoration-elements/decoration-elements.md` 纪律） |

## 四、不要照抄的三件事

1. **整页图片页**：Airflow 33 页 0 形状 0 文本框，违反"核心内容原生可编辑"红线；
2. **无备注**：样本 8 份的讲者备注全部为空，本包要求每页备注；
3. **无梯度字号**：样本字号跨度 5–287pt、标题档位 1–9 个，本包按 H1–H4 / Body / Caption / Metric 固定 7 档。
