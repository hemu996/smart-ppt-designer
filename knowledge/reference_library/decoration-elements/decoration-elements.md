# 装饰元素（从样本实测）

样本的"高级感"很大一部分来自**装饰件**：金色纹样、发光线条、印章、云纹、粒子。
实测 8 份样本每页图片 5–15 张、且"占画布 ≥25% 的大图占比≈0"——说明这些图片基本都是**小尺寸装饰件**，不是配图。

## 一、四类装饰元素与实现方式

| 类型 | 用途 | 实现方式 | 本包对应 |
|---|---|---|---|
| **金线 / 分隔线** | 标题下方短横线、章节带、卡片顶边 | 原生细长矩形（`rect`，高 0.06–0.09in） | 页面计划 `shape` 元素，`z_index` 10–19 |
| **传统纹样 / 印章 / 云纹** | 封面与章节页的国风质感 | 生图 PNG（透明背景），作为 L2 装饰层 | `assets/effect-templates/pattern-border.json` |
| **发光线条 / 粒子** | 科技类背景与边框 | 生图 PNG，透明度 50–80% | `assets/effect-templates/glow-decor.json`、`tech-particles.json` |
| **烫金 / 书法标题** | 封面与章节主标题 | 生图 PNG（透明背景），作 L4 标题层 | `assets/effect-templates/gold-calligraphy.json` |

## 二、样本实测的装饰使用特征

| 样本 | 图/页 | 组/页 | 每页色值 | 装饰风格 |
|---|---|---|---|---|
| 16页-国奖红金 | 15.4 | 21.6 | 11.6 | 金色装饰件密铺 + 大量组合复用（装饰最重） |
| 东方遗韵 | 10.8 | 13.5 | 12.3 | 棕金纹样 + 组合复用 |
| 刺绣文化 | 5.1 | 3.9 | 7.7 | 青金细线 + 少量纹样 |
| 04 中国风 非遗乐器 | 8.6 | 7.8 | 6.7 | 深底棕金纹样 |
| 红色国风非遗文化 | 6.7 | 12.9 | 3.1 | 棕金底 + 极简用色（色值最收敛） |
| 红色党建帮助老人 | 6.4 | 4.8 | 5.7 | 深红底 + 浅金线条 |
| 财务云教育平台 | 7.8 | 9.2 | 6.8 | 深蓝底 + 青绿发光线条 |
| Airflow（医疗） | 5.6 | 0.3 | 6.2 | 整页图片，无矢量装饰 |

要点：**装饰件以"组"为单位复用**（组/页 0.3–21.6），做一次、多页复制，这是样本压工期的关键手法。

## 三、使用纪律（结合本包红线）

1. 装饰件放 **L2 层（z_index 10–19）**，内容层 20–29、标题层 30–39，装饰不得遮挡文字；
2. 每页色值**不超过 6 个**：样本最高 11.6/页，本包按视觉系统 6 色 + 图表调色板执行，**不要照抄**；
3. 生图数量仍按红线控制在 **3–5 张/份**（装饰件优先复用，不逐页生成）；
4. 装饰面积：单页强调色（`accent`）占比 ≤8%，金色只作线描与点缀；
5. 烫金/发光/渐变文字**不得**用 PptxGenJS 硬做，统一用生图 PNG（红线第 9 条）。
