# 参考稿手法实测库

本目录保存**素材库参考稿的实测数据与台账**，用来回答两件事：这些参考稿是怎么做出来的、本包的规范与它们差在哪。

## 一、目录

| 路径 | 内容 |
|---|---|
| `craft-ledger.md` | 手法台账：逐份实测基线、共性手法、做法分型、逐页卡片映射、配色与字号量化、与技能的对照、可复用套路清单 |
| `data/<slug>.json` | 每一份参考稿的逐页明细（角色、版式、形状/组合/图片数、原生表图、文本块、色数、字号、图层顺序、几何、用色） |
| `data/_all.json` | 全部稿件的汇总指标 |
| `data/_mapping.json` | 逐页卡片映射的分布、覆盖率与解析失败清单 |
| `../$references/` | 参考原文件本体在 `assets/templates/references/`（只读保留，不修改） |

## 二、怎么用

1. **选风格**：先看 `assets/style-index.json` 与 `assets/style-cards/`；要判断"这套风格真实用法"时来本目录看逐页明细。
2. **写规范或改脚本**：以 `craft-ledger.md` 的对照表为依据；可复用套路见 `references/reference-craft.md`。
3. **用户给了新的参考稿**：先按素材库流程入库，再重新生成实测数据（见下）。

## 三、怎么重新生成

```bash
python scripts/analyze_reference.py                       # 默认读 assets/templates/references
python scripts/analyze_reference.py --ref-dir <目录> --out-dir knowledge/reference_analysis/data
```

脚本只做静态 XML 统计（不启动 PowerPoint、不调 COM），可重复执行、结果可复核。

## 四、当前规模与结论摘要

- 参考稿 10 份可解析 pptx、共 **170 页**；1 份损坏（`巧夺天工改.pptx`，165 字节），2 份 PDF 与同名 pptx 为同一设计。
- 逐页可映射到本包已卡片化结构：**132 / 170 页 = 78%**；未映射的 38 页中 33 页是"整页图片"形态（本包红线禁止）。
- 参考稿**没有统一字号梯度**（标题档 1–9 个、跨度 5.7×–31.9×）、**没有讲者备注**（10/10 为空）、**几乎没有动效**（1 页动画、1 份转场）、**原生表图用得克制**（6 份表格页、7 份图表页，各 1–4 页）。

## 五、使用纪律

- 这里的数字是**参考稿的实况**，不是本包的标准。两者冲突时，**以本包 `references/` 的规范为准**（红线：原生可编辑、每页备注、统一字号梯度、显式图层）。
- 页面角色与卡片映射是启发式推断（按字数、字号、是否含表图），不等于原作者的页面命名；引用时如实标注为推断。
