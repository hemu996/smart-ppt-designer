## 二、共性手法（10 份共同或高度一致的做派）

1. **基础图元拼版**：几何预设 `rect` 2551 次、`roundRect` 512、`ellipse` 475、`parallelogram` 266、`trapezoid` 126。高级版面几乎全靠基础图元 + 对齐完成。
2. **先做组件、再整组复用**：组/页 0–31.5（黑金 31.5、红金 21.5、芯片 19.1、非遗 12.9）。
3. **图片主要当装饰**：图/页 1–15.4，但"占画布 ≥25% 的大图"占比几乎为 0（唯一例外 Airflow=1.00）。
4. **大字标题 + 两极字号**：最大字号 80–287pt，最小字号 5–14pt，字号跨度 5.7×–31.9×，且每份标题档 1–9 个、正文档 4–11 个——没有统一梯度。
5. **原生数据对象用得克制**：6 份出现原生表格页（各 1–4 页）、7 份出现原生图表页（各 1–3 页）。
6. **几乎没有动效与备注**：仅 1 页含动画时间线、1 份含转场；10 份稿件的讲者备注页全部为空。
7. **版式复用度低**：多为 1–3 个版式（医疗器械 7 个），设计主要落在页面元素上。

| B 信息编排型 | 非遗、医疗器械、茶产业 | 形/页 16–68、字/页 120–219，原生图表/表格更多 | 先划内容模块，再用图表/表格承载数据 |

## 四、逐页结构与卡片映射（深化）

把每页按结构映射到技能包 `knowledge/cards/` 的卡片与 `assets/layout-templates/` 的版式：

| 映射到的结构 | 页数 | 说明 |
|---|---|---|
| `layout-sidebar-nav`（多模块内页） | 89 | 参考稿内页的绝对主力形态 |
| 整页视觉（封面/图主导） | 38 | 其中 33 页来自 Airflow，属技能包红线禁止的整页图片形态 |
| `layout-data-dash`（含原生表/图） | 24 | 有原生表格或图表的页面 |
| `cover-title`（封面/章节/结尾） | 19 | 含章节页与结尾页 |

- **可映射覆盖率：132 / 170 页 = 78%**；其余 38 页中 33 页是"整页图片"形态，技能包不提供对应卡片（红线禁止）。
- **细粒度语义卡片（四宫格、双栏、时间线、层级树、漏斗、对比矩阵、指标强调、问题—方案）在参考稿中未被区分出来**：参考稿的页面在 XML 层面高度同质，都是"多模块 + 文字块"，语义要靠内容判断。这说明**技能包的卡片体系比参考稿的实际做法更细**，而不是参考稿更丰富。

## 六、与技能包逐条对照

### 已覆盖（参考稿有，技能包有对应实现）

| 参考稿手法 | 技能包对应 |
|---|---|
| 多模块高密度内页（89 页） | `sidebar-nav` / `four-grid` 版式 + 11 张设计卡片 |
| 装饰件与特效层 | 4 类特效模板 + L2 装饰层（z 10–19） |
| 封面/章节超大字号 | 章节页 120pt 编号 + 封面大字规范 |
| 组件复用（组/页 ≤ 31.5） | 5 个母版/版式 + 64 图标 + 卡片结构 |
| 数据用原生对象（24 页） | `data-dashboard` 强制原生图表/表格 |

### 技能包更严格或不同

| 维度 | 参考稿实测 | 技能包规定 |
|---|---|---|
| 图表/表格 | 常用图形或图片替代，原生对象少 | 红线强制原生图表 + 原生表格可编辑 |
| 讲者备注 | 10 份全部为空 | 每页四段式备注，缺页判 error |
| 字号 | 5–287pt、1–9 档无梯度 | 固定 7 档梯度（H1 36–44 / H2 28–32 / H3 20–24 / H4 16–18 / Body 13–15 / Caption 10–11 / Metric 40–60） |
| 配色 | 每页 0–11.6 个色值，无上限 | 6 个色 + 图表调色板 |
| 图层 | 靠分组与绘制次序 | 显式 `z_index` 四层 |
| 转场 | 基本没有 | 每页统一 fade |
| 整页图片 | Airflow 全篇（33 页） | 红线禁止整页图片页 |

### 参考稿有、技能包未覆盖（可评估，本轮未实施）

1. **超大字档**：封面/章节 100–287pt 主视觉字，技能包最大 H1 44pt / Metric 60pt。
2. **装饰件密度**：图/页最高 15.4，技能包仅 4 类特效模板，未定义密度参数。
3. **组件组级别复用**：技能包没有"组件组"概念，跨页改一处需改多页。
4. **预设几何装饰**：参考稿用 parallelogram / trapezoid / homePlate / plaque 等，技能包几何以 rect / roundRect / ellipse 为主。

### 参考稿做法不采纳

- 整页图片拼装（33 页，违背"核心内容原生可编辑"红线）；
- 备注全部留空（10/10）；
- 5–9pt 极小正文（低于技能包 10pt 下限，投影不可读）。

## 七、可复用套路清单

| # | 套路 | 参考依据 | 对应卡片 / 模板 |
|---|---|---|---|
| 1 | 封面：大字主视觉（≥40pt）+ 一处装饰件带 + 信息行 | 最大字号 80–287pt | `cover-title` / `cover-full-image` |
| 2 | 装饰件按"组"做一次、跨页复用 | 组/页 2–32 | 特效模板 + 母版装饰层 |
| 3 | 内页只用 rect / roundRect / ellipse 三类图元 + 12 列对齐 | rect 2551、roundRect 512、ellipse 475 | 版式模板 zones |
| 4 | 图主导页：字/页 ≤ 80，图片承担主视觉 | 38 页整页视觉（除 Airflow） | `cover-full-image` |
| 5 | 章节页：超大字形 + 极少文字（≤14 字） | 芯片/红金章节页 | 章节页规范（120pt 编号） |
| 6 | 数据页克制使用原生图表（每份 1–3 页） | 原生图表页 1–3 | `layout-data-dash` / `data-dashboard` |
| 7 | 多模块内页：模块内部结构一致（图标+小标题+要点） | 共性手法 1、2 | `layout-sidebar-nav` / `layout-four-grid` |
| 8 | 配色收敛：单页色值控制在 3–6 个（不要学红金的 11.6，也不必压到黑金的 2.2） | 每页色数 2.2–11.6 | 视觉系统 6 色 + 图表调色板 |
