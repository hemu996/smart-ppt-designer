# 品牌固定模板（可选）

这里放"某个单位/品牌长期固定"的视觉约定，例如公司 VI、学校标识、固定的封面版式。**没有固定品牌要求时，本目录可以一直为空**——不要为了填满而编造品牌规范。

## 一、模板文件命名

`<brand-key>.md`，例如 `acme-health.md`。品牌色、字体、Logo 都存在这一个文件里，不要拆散。

## 二、模板内容（建议字段）

```markdown
---
brand_key: acme-health
display_name: XX 健康服务集团
---

## 品牌色
| 用途 | 色值 | 说明 |
|---|---|---|
| 主色 | 1F4E79 | 标题条、强调块 |
| 辅色 | 2E75B6 | 次级结构、图表第 2 系列 |
| 禁用色 | FF0000 | 仅用于风险警示，不用于装饰 |

## 固定元素
- Logo 文件：`assets/logo_acme.png`（放在封面左上角，x 0.6in / y 0.5in / 高 0.6in）
- 页脚固定文案："XX 健康服务集团 ｜ 内部资料"

## 版式约定
- 封面固定用 `title-cover` 纯色极简变体，不使用生图
- 正文字体固定"微软雅黑"，禁止宋体
```

## 三、怎么用

1. 用户明确说"用我们的品牌模板/VI"时，先读对应品牌的 md；
2. 把品牌色写进该次生成的 `assets/config.json` 的 `theme`（或生成后单独改色）；
3. 品牌约定优先于 `image-styles.json` 的风格预设配色，但**风格统一原则不变**：整份 PPT 仍只用一套风格；
4. 品牌模板里禁用生图时，`image_required` 全部置 `false`，封面走纯色背景（属于正常降级路径，不是失败）。

## 四、注意

- 品牌色与风格预设冲突时，以品牌为准，并在交付说明里提一句。
- 不要把品牌 Logo 或色值当成"通用知识"套到没有品牌要求的任务上。
